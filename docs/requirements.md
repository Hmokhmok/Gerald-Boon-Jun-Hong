# Requirements

## Functional requirements (what the system must DO)
1. allow students to register their events on 
2. allow student to update the details of their event 
3. allow the students to see the details of the event and whether the event got approval by the admins
4. allow admins to see the details of the event proposed by the students
5. allow admins to approve or reject event proposal of the students

## Non-functional requirements (how the system must PERFORM)
1. The system will launch all parts whether that's the homepage, admin page or detail of the event in a time frame of at least 1 second
2. the system will crash only 0.01 percent of the time a user or admin uses the system
3. The system will make changes when an admin or student apply those changes in a time frame of at least 2 seconds
